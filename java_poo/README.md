# Java POO projects

The Maven projects in this directory target **Java 25 LTS** and require a Java
25 JDK to compile and run:

- `exemplo_dao`
- `aula_bd/demo`

From either project directory, run `mvn clean test` to compile the application
and execute its available tests. The compiler uses Maven's `release` setting so
the generated bytecode and accessible Java APIs match the Java 25 target.
